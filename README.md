# Высоцкий Кирилл 02171-ДБ
## Тематика сайта: WEB-приложение "Викторина". Название: WEB-разработка.
### Целевая аудитория сайта - пользователи, которые только недавно начали изучать WEB-разработку, пользователи, которые освоили базовые знания, и для пользователей, которые работают программистами в области WEB-разработки и желают углубить, закрепить свои знания в этой области.
---
*Потребность в информации этих пользователей:*
1. *Пользователи могут проверить и закрепить свои знания HTML, CSS и JavaScript языков.*
2. *Благодаря нескольким уровням (базовый, средний, продвинутый) викторины, пользователи смогут получить немного новой для них информации, о которй они могли не знать или забыть.*
3. *Возможность сравнить свой уровень знаний с остальными пользователями сайта, что даёт больше мотивации в обучении и закреплении знаний в данной области.*
4. *С помощью данного сайта, пользователи, которые только начали изучать WEB-разработку, смогут получить мотивацию учиться в этом направлении, поскольку на сайте короткие сессии и нет длинных и непонятных текстов, что упрощает получение знаний.*
---
**Особенности, которые можно использовать для привлечения внимания.**
1. **Если сайт будут посещать пользователи, которые занимаются в IT-специальности или учатся в этой области, то сайт можно сделать похожим на среды разработки (напримерБ VS Code, или WebStorm), чтобы пользователям было комфортно на сайте.**
2. **Чтобы пользователи получали ещё больше удовольствия, можно добавить локальный юмор, который знают только программисты и разработчики.**
3. **Также можно сделать систему рангов, так у пользователей будет больше мотивации возвращаться на сайт, чтобы получить высокий ранг.**
4. **Поскольку мой сайт рассчитан как на профессионалов, так и на новичков, то можно выбрать два варианта объяснения ответа. То есть, один вариант ответа будет на профессиональном языке, рассчитанный на более продвинутых пользователей. А второй вариант - на новичков.**
5. **Также, чтобы пользователи стали чаще посещать сайт, можно создать систему достижений, за выполения определённых условий, ведь каждому пользователю нравится получать награду.**
---
*Функциональные возможности WEB-приложения:*
1. *Система очков: подсчёт баллов будет зависеть от правильности ответа.*
2. *Рейтинг: на сайте в отдельной странице будет отображена таблица топ 5 лучших пользователей. Также эти данные будут сохранены даже при перезагрузке страницы.*
3. *Найстройка игры: можно выбрать уровень вопросов (базовый, средний, продвинутый); можно будет выбрать категорию вопросов, т.е. какой-то конкретный язык, или выбрать по всем языкам WEB-разработки.*
4. *Обучающая состовляющая: после прохождении теста будут показываться количество общее количество баллов, правильные и неправильные ответа. В нерпавильных ответах, будут показываться объяснения, и в эти объяснения можно добавить локальный юмор для программистов.*
5. *Система ачивок: при выполнении каких-то условий, в профиль будут добавляться достижения.*
