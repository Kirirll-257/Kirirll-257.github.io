# Итоговый проект по дисциплине Веб-технологии

## ФИО студента, номер учебной группы

Высоцкий Кирилл 02171-ДБ

## Тематика сайта, название

Интерактивная игра-викторина "WEB-разработка".

## Целевая аудитория

1. Начинающие: студенты и самоучки, которые только начали знакомиться с WEB-разработкой.
2. Пользователи с базовыми знаниями: люди, которые освоили базовые принципы WEB-разработки, но не работающие в IT-сфере.
3. Профессионалы: люди, работающие в IT-сфере, желающие закрепить теорию или закрыть пробелы в знаниях.

## Содержание сайта

* начальная страница с правилами игры
* основная страница с игровым полем
* ...

## Потребность в информации этих пользователей

1. Диагностика и закрепление: пользователи могут проверить и закрепить свои знания синтаксиса и стандартов HTML, CSS и JavaScript языков.
2. Поиск новой информации и повторение пройденного материала: разделение викторины на уровни (базовый, средний, продвинутый) позволяет пользователям получать информацию, соответствующую их текущему уровню, а также вспоминать детали, которые могли быть забыты со временем или упущены при самостоятельном изучении.
3. Объективная оценка уровня: возможность сравнить свой уровень знаний с другими пользователями сайта, что даёт чёткое понимание текущего прогресса.
4. Упрощённое обучение: короткие игровые сессии и отказ от длинных теоретических текстов снижают когнитивную нагрузку, поддерживает мотивацию новичков и позволяет учиться в перерывах между основными задачами.

## Функциональные возможности

1. Система очков: подсчёт баллов будет зависеть от правильности ответа.
2. Рейтинг и сохранение: на сайте в отдельной странице будет отображена таблица топ 5 лучших пользователей. Также эти данные будут сохранены даже при перезагрузке страницы.
3. Найстройка игры: 
* Выбор уровня сложности: базовый, средний, продвинутый.
* Фильтрация по категориям (HTML, CSS, JavaScript или смешанный вид)
* Настройка количества вопросов.
4. Обучающая составляющая: 
* Итоговая статистика: общее количество баллов, процент правильных ответов.
* Детальный разбор всего теста: после завершения игры можно посмотреть ответы с пояснениями и юмором.
5. Система ачивок: коллекция наград в профиле пользователя, открывающаяся при выполнении определённых условий.
6. Пауза в игре с сохранением текущего состояния.
7. Адаптивная вёрстка для корректного отображения на мобильных устройствах и планшетах.

## Особенности, которые можно использовать для привлечения внимания
1. Стилистика в программисткой среде: интерфейс будет выполнена в тёмной теме с моноширными шрифтами и элементами, напоминающими среды разработок. Это создаст комфортную и привычную атмосферу для IT-аудитории.
2. Профессиональный юмор: в пояснениях к ответам используются локальные шутки и отсылки, понятные только разработчикам.
3. Система рангов: звания начисляются в зависимости от набранных очков. Это геймецифирует процесс и даёт дополнительную мотивацию возвращаться для повышения статуса.
4. Адаптивные пояснения: переключатель режимов объяснения ответа в конце теста:
* "Простыми словами" - выбор для новичков.
* "Профессионально" - терминология и спецификации для продвинутых.
5. Система достижений(ачивок): визуальные награды за выполнение условий, которые собираются в личном профиле.
